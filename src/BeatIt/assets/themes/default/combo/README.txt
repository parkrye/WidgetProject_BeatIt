테마 폴더 구성

effects/   때릴 때 튀는 이펙트. 여기 있는 이미지 중 하나가 랜덤으로 뜬다.
           장수 제한 없음. 폴더를 비우면 이펙트가 안 뜬다.
           동시에 여러 개가 뜰 수 있어서 GIF 는 첫 프레임만 쓴다.

combo/     콤보 숫자 그리는 법. 아래 순서로 있는 걸 쓴다.
           1) 0.png ~ 9.png 가 전부 있으면 그 그림으로 그린다. label.png 가 있으면 COMBO 자리에 쓴다.
           2) 숫자 그림이 없고 .ttf / .otf 가 있으면 그 폰트로 그린다.
           3) 둘 다 없으면 기본 글꼴로 그린다.

이 폴더를 통째로 복사해서 이름만 바꾸면 새 테마가 된다.
설정 창에서 테마를 고르고, 크기와 위치도 거기서 맞춘다.
