캐릭터 폴더 구성

idle/      가만히 있을 때. 여기 있는 이미지 중 하나가 랜덤하게 갈아 끼워진다. 이것만 필수다.
move/      끌려가거나 혼자 걸을 때.
beat/      맞을 때.
sounds/    행동별 소리. sounds/README.txt 참고.

move 와 beat 는 그 아래 방향 폴더로 한 겹 더 나눌 수 있다.

  default/   방향을 안 따질 때 쓴다.
  left/      move 는 왼쪽으로 갈 때, beat 는 캐릭터 왼쪽을 때렸을 때.
  right/     오른쪽.
  up/        위.
  down/      아래.

방향 폴더를 안 만들고 move/ beat/ 에 이미지를 바로 넣어도 된다. 그건 default 로 친다.
없는 방향은 default 로, default 도 없으면 idle 로 대신한다.
같은 폴더에 여러 장을 넣으면 그중 하나가 랜덤으로 뜬다. 장수 제한 없고 GIF 도 섞어 쓸 수 있다.

이 캐릭터(clawd)는 일부러 두 가지 방식을 섞어 두었다.
move 는 방향 폴더로 나눠 두었고, beat 는 폴더에 이미지를 바로 넣었다. 둘 다 된다는 뜻이다.

이 폴더를 통째로 복사해서 이름만 바꾸면 새 캐릭터가 된다.
