캐릭터 소리 넣는 곳

sounds/idle/   가만히 있을 때 가끔 난다. 간격은 설정 창 '소리' 탭에서 정한다.
sounds/move/   끌려가거나 혼자 걷기 시작할 때 한 번 난다. 방향이 꺾일 때는 다시 안 난다.
sounds/beat/   맞을 때마다 난다.

각 폴더에 여러 개를 넣으면 그때그때 하나를 무작위로 골라 튼다.
길이는 상관없고, 이미 나던 소리가 다시 걸리면 처음부터 다시 난다.

형식은 wav / mp3 / wma / m4a / aac 가 별도 설치 없이 난다.
ogg / flac / opus 는 그 코덱이 깔려 있어야 나고, 못 여는 파일은 알아서 목록에서 빠진다.

볼륨과 음소거는 설정 창 '소리' 탭에 있다.
