# BeatIt

화면 맨 위에 떠 있는 샌드백 위젯. 클릭하면 줘터지고, 연타하면 콤보가 쌓인다.

## 실행

```bash
dotnet run --project src/BeatIt
```

빌드 결과물은 `src/BeatIt/bin/Debug/net10.0-windows/BeatIt.exe`.

## 조작

| 입력 | 동작 |
|---|---|
| 좌클릭 | 타격. 꾸겨졌다 튀어오른다 |
| 좌클릭 연타 | 콤보 누적. 숫자가 커지고 색이 붉어지며 타격 강도도 세진다 |
| 좌클릭 드래그 | 붙잡은 지점이 커서를 따라오고 몸통은 뒤처지며 쭉 늘어난다. 놓으면 출렁이며 돌아온다 |
| 우클릭 | 설정 / 항상 위에 / 위치 잠금 / 종료 |

## 이미지 설정

우클릭 → **설정**에서 두 가지 모드 중 하나를 고른다.

- **단일 이미지** — 한 장을 계속 꾸겨서 쓴다. GIF를 넣으면 계속 재생된다.
- **이미지 시퀀스** — 때릴 때마다 다음 장으로 넘어간다. **장수 제한 없이** 추가할 수 있고, 순서를 위/아래로 바꿀 수 있다. 끝까지 가면 처음으로 돌아온다. PNG·JPG·**GIF** 섞어서 써도 된다.

이미지를 하나도 지정하지 않으면 기본 샌드백이 대신 맞는다.

같은 화면에서 위젯 크기와 콤보 유지 시간(이 시간 안에 다시 때려야 콤보가 이어진다)도 조절한다.

설정은 `%AppData%\BeatIt\settings.json` 에 저장된다.

## 구조

```
src/BeatIt/
  Core/       타격·드래그 애니메이션, 콤보, 스프라이트 소스, GIF 재생
  Models/     저장되는 설정 모델
  Services/   설정 파일 입출력
  Views/      위젯 창, 설정 창
  Controls/   콤보 표시
```

- 애니메이션은 Storyboard 대신 감쇠 스프링(`Core/Spring.cs`)으로 돌린다. 타격을 임펄스로 밀어넣기 때문에 연타하면 흔들림이 끊기지 않고 누적된다.
- GIF는 외부 패키지 없이 `GifBitmapDecoder` 로 프레임을 직접 합성한다(`Core/AnimatedGifPlayer.cs`). 부분 갱신 프레임과 disposal 규칙을 처리한다.
- 이미지 모드는 `ISpriteSource` 뒤에 숨어 있어서, 모드를 추가해도 창 코드는 건드리지 않는다.

## 알아둘 점

- 창 크기는 현재 이미지의 비율로 잡는다. 시퀀스에 비율이 다른 이미지를 섞으면 나머지는 그 상자 안에 `Uniform` 으로 맞춰 들어간다.
- 늘어나고 흔들려도 잘리지 않게 창을 이미지보다 넉넉히 잡아두었다. 남는 여백은 클릭이 통과한다.
